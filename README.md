# QueueCare Medical - Integrated Hospital Queue Management System

QueueCare Medical is a web-based healthcare management platform designed to streamline patient registration, optimize doctor appointment schedules, and balance emergency walk-ins with scheduled visits[span_1](start_span)[span_1](end_span).

## 🏥 Features & Roles

* **Patient Portal (`patient-dashboard.html`):** Allows patients to view wait times, track live queue positions, and schedule appointments[span_2](start_span)[span_2](end_span).
* **Doctor Dashboard (`doctor-dashboard.html`):** Enables physicians to manage consultation queues, view patient check-ins, and update status in real time[span_3](start_span)[span_3](end_span).
* **Admin Dashboard (`admin-dashboard.html`):** Provides hospital administrators with overview metrics, emergency queue prioritizations, and system settings[span_4](start_span)[span_4](end_span).
* **Authentication (`login.html`):** Unified entry point for patients, doctors, and staff to log into their respective portals[span_5](start_span)[span_5](end_span).

## 🛠️ Tech Stack

* **Front-end:** HTML5, CSS3, JavaScript (ES6+)[span_6](start_span)[span_6](end_span)
* **UI/UX Design:** Responsive layout designed for desktop and mobile healthcare access[span_7](start_span)[span_7](end_span)
